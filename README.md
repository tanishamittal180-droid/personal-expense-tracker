💸 Personal Expense Tracker with Data Visualization
📌 Project Overview
The **Personal Expense Tracker** is a full-stack Python application that allows users to **track, analyze, and manage their expenses in real time**.
It includes **user authentication, expense logging, budget management, and interactive dashboards** built using Streamlit.
This project demonstrates real-world skills in:
* Data Analysis
* Backend Development
* Database Management
* Data Visualization
* Basic Machine Learning (extendable)
## 🎯 Problem Statement
Many individuals struggle to understand where their money is going.
This project solves that problem by:
* Tracking daily expenses
* Categorizing spending
* Visualizing trends
* Providing budget alerts
## 🚀 Features
### 🔐 Authentication
* User Signup & Login
* Secure password hashing
### 💸 Expense Management
* Add expenses in real-time
* Categorize transactions
* Store data in SQLite database
### 📊 Data Visualization
* Category-wise spending (Bar Chart)
* Daily spending trend (Line Chart)
* KPI metrics (Total, Average, Max spend)
### 💰 Budget System
* Set category-wise budgets
* Get alerts when spending exceeds limit
### 📄 Dashboard
* Interactive UI using Streamlit
* Clean fintech-style layout
* Transaction history table
